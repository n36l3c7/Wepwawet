Installation

Packages for Debian, Ubuntu, Kali, Fedora and Arch Linux, plus an AppImage for anything else.

Requirements

  • Linux on x86_64 or arm64.
  • Tested on Debian 13, Ubuntu 22.04 and 24.04, Kali Rolling, Fedora 43 and Arch Linux.
  • On arm64, glibc 2.39 or newer (Ubuntu 24.04+, Debian 13+), required by Qt.
  • About 190 MB to download and 515 MB of disk. The packages bring their own Python 3.12 and Qt WebEngine.
  • An X11 or Wayland session for the window; without one, use wepwawet serve.

Install a package

Download the file for your system from the releases page. Each release also has a SHA256SUMS file.

Debian, Ubuntu, Kali

sudo apt install ./wepwawet_0.3.0-1_amd64.deb

Fedora

sudo dnf install ./wepwawet-0.3.0-1.x86_64.rpm

Arch Linux

sudo pacman -U wepwawet-0.3.0-1-x86_64.pkg.tar.zst

The packages install the system libraries Qt needs. They recommend mtr and traceroute, which Wepwawet will use to measure from this machine.

AppImage

chmod +x Wepwawet-0.3.0-x86_64.AppImage
./Wepwawet-0.3.0-x86_64.AppImage

An AppImage needs libfuse2; without it, add --appimage-extract-and-run. It also expects the libraries Qt WebEngine loads. On Debian-based systems: 

sudo apt install libgl1 libegl1 libfontconfig1 libdbus-1-3 libxkbcommon0 libxkbcommon-x11-0 libxcb-cursor0 libxcb-icccm4 libxcb-image0 libxcb-keysyms1 libxcb-randr0 libxcb-render-util0 libxcb-shape0 libxcb-xinerama0 libxcb-xkb1 libx11-xcb1 libnss3 libxcomposite1 libxdamage1 libxrandr2 libxtst6 libxkbfile1 libxfixes3 libgssapi-krb5-2 libglib2.0-0t64 libasound2t64 liblcms2-2 libminizip1t64 libopus0 libsnappy1v5 libwebp7 libwebpdemux2 libwebpmux3

Download the GeoIP databases

The databases are not shipped with the packages (their licences require it). Download them once, then monthly: 

wepwawet data update
  • DB-IP Lite City is always downloaded: no account needed. IP geolocation by DB-IP, CC BY 4.0.
  • IPinfo Lite (country and ASN) needs a free token from ipinfo.io.
  • MaxMind GeoLite2 City and ASN need a free MaxMind account ID and licence key.

The same command downloads the GeoNames list of cities above 15 000 inhabitants (CC BY 4.0), used to name the places inside a measured region.

See API keys for where to put tokens. Even without any database, RIPEstat serves the GeoLite2 answer for each lookup.

Check the installation

wepwawet doctor

It checks Python, the configuration, the directories, the window engine and the traceroute tools, and says how to fix what is missing.

Measuring from this machine

Traceroute needs raw sockets. On Debian, Ubuntu and Kali, mtr already works without root. For scamper, give the capability to the tool, never to Wepwawet, and never run Wepwawet as root: 

sudo setcap cap_net_raw+ep "$(command -v scamper)"

Uninstall

sudo apt remove wepwawet      # Debian, Ubuntu, Kali
sudo dnf remove wepwawet      # Fedora
sudo pacman -R wepwawet       # Arch Linux

Your settings and history stay in ~/.config/wepwawet, ~/.local/share/wepwawet and ~/.cache/wepwawet; delete them to remove everything.

From source

For development, with Python 3.12, uv and Node.js 22:

git clone https://github.com/n36l3c7/Wepwawet.git && cd Wepwawet
uv sync --extra gui
(cd frontend && npm ci && npm run build)
uv run wepwawet
