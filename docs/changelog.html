0.1.0 · 2026-11-14

First release: the application, without geolocation yet.

Added

  • Desktop window (Qt WebEngine): wepwawet with no arguments opens it; wepwawet gui --browser opens the system browser instead.
  • Interface with the "Sand & turquoise" terminal theme and the animated ASCII jackal.
  • MapLibre map with CARTO dark (online, recoloured) and an offline Natural Earth map.
  • Local API bound to loopback with a per-session token, a Host check and a strict Content Security Policy; live log over server-sent events.
  • Command line: gui, serve, doctor, version; wpw alias.
  • Configuration file and environment variables, XDG directories, log redaction, SQLite cache.
  • Packages for x86_64 and arm64: .deb, .rpm, Arch Linux and AppImage.
