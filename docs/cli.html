CLI reference

Like Wireshark: wepwawet alone opens the window, sub-commands work in the terminal. wpw is a short alias.

wepwawet / wepwawet gui

Open the application window. The local server starts on a free loopback port with a new session token and stops when the window closes.

Option Meaning
--browser Open the interface in the system browser instead of a window. Stop with Ctrl+C.

wepwawet locate TARGET

Locate an IP address or hostname from the terminal and print the evidence. Progress goes to stderr, the report to stdout.

Option Meaning
--format, -f json, geojson, kml, md or csv (hops) instead of the table.
--output, -o Write the export to a file instead of standard output.
--json Same as --format json.
--passive Passive sources only: no measurements.

Every run is saved to the history.

wepwawet history

Command Meaning
history list [QUERY] [--limit N] Past runs, most recent first.
history show RUN Print a past run.
history diff OLD NEW [--address IP] What changed between two runs.
history export RUN -f FORMAT [-o FILE] Export a past run.

wepwawet bulk FILE

Locate every target in FILE (one per line, # for comments, up to 1 000) one after the other, and print a summary CSV: query, address, status, city, country, coordinates, uncertainty, confidence, anycast, network class, ASN, error.

Option Meaning
--max-tests N Test budget for the whole list (default 500).
--passive No measurements at all.
--output FILE Write the summary CSV to a file.

wepwawet providers

List the sources and whether each can run now (a missing key or database is named).

wepwawet data update / wepwawet data status

Download the free GeoIP databases, the GeoNames city list and the airport and UN/LOCODE codes used to read router names, or list the installed GeoIP databases. --only dbip|ipinfo|geolite|geonames|places (repeatable) limits the update. A failed download never replaces a working database.

wepwawet benchmark

Locate RIPE Atlas anchors and report the error per stage against their published positions.

Option Meaning
--anchors N How many anchors (default 10), one per country first.
--max-tests N Tests per anchor (default 100); 0 for passive only.
--seed N Seed of the sample, for repeatable runs.
--output FILE Per-anchor CSV with the error of every stage.

wepwawet serve

Start only the local server and print the address to open, including the session token. The token is new at every start unless WEPWAWET_TOKEN sets one (24 characters or more), for scripts that call the API.

Option Meaning
--host HOST Address to listen on. Non-loopback addresses need server.allow_remote = true.
--port PORT Port; default a free one.

wepwawet doctor

Check Python, the configuration, the directories, the window engine and the local traceroute tools. Exits with 1 when a check fails.

wepwawet version, --version, -V

Print the version.

Exit codes

Code Meaning
0 Success
1 A doctor check or a database download failed
2 Invalid input, configuration or arguments, or the window cannot open

Local API

The interface talks to the local server over HTTP. Every route except /api/health needs the session token (cookie set by /auth?token=…, or Authorization: Bearer).

Route Answer
GET /api/health {"status": "ok"}
GET /api/meta Version and base map settings
GET /api/providers Sources, each with the reason it cannot run (or null)
GET /api/budget What each measurement source has left (tests this hour, credits)
GET /api/settings, PUT /api/settings The options the settings panel can change, the sources and which keys are set (never their values); body {"values": {"map": {"basemap": "offline"}}}, 422 for an invalid value, 409 during a run
PUT /api/settings/keys/{name}, DELETE /api/settings/keys/{name} Body {"value": "…"}; stores or removes a key in secrets.toml
POST /api/runs Body {"query": "…"}; starts a run (202), 409 while another runs
GET /api/runs, GET /api/runs/{id} Recent runs; one full report
DELETE /api/runs/{id} Cancel a running run
GET /api/runs/{id}/export?format= Download as json, geojson, kml, md or csv
GET /api/history?query=&limit= Past runs
GET /api/history/diff?a=&b= Changes between two runs
DELETE /api/history/{id} Forget a run
POST /api/bulk Body {"queries": [...], "max_tests": 500, "passive": false}
GET /api/bulk/{id}, DELETE /api/bulk/{id} Queue status; cancel
GET /api/bulk/{id}/export?format=csv|geojson Summary of a bulk run
GET /api/events Server-sent events: ready, run, target, bulk, log
