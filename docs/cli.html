CLI reference

Like Wireshark: wepwawet alone opens the window, sub-commands work in the terminal. wpw is a short alias.

wepwawet / wepwawet gui

Open the application window. The local server starts on a free loopback port with a new session token and stops when the window closes.

Option Meaning
--browser Open the interface in the system browser instead of a window. Stop with Ctrl+C.

wepwawet locate TARGET

Locate an IP address or hostname from the terminal and print the evidence. Progress goes to stderr, the report to stdout.

Option Meaning
--json Print the full report as JSON (UTF-8, for scripts).
--passive Passive sources only: no ping campaign.

wepwawet providers

List the sources and whether each can run now (a missing key or database is named).

wepwawet data update / wepwawet data status

Download the free GeoIP databases and the GeoNames city list, or list the installed ones. --only dbip|ipinfo|geolite|geonames (repeatable) limits the update. A failed download never replaces a working database.

wepwawet serve

Start only the local server and print the address to open, including the session token.

Option Meaning
--host HOST Address to listen on. Non-loopback addresses need server.allow_remote = true.
--port PORT Port; default a free one.

wepwawet doctor

Check Python, the configuration, the directories, the window engine and the local traceroute tools. Exits with 1 when a check fails.

wepwawet version, --version, -V

Print the version.

Exit codes

Code Meaning
0 Success
1 A doctor check or a database download failed
2 Invalid input, configuration or arguments, or the window cannot open

Local API

The interface talks to the local server over HTTP. Every route except /api/health needs the session token (cookie set by /auth?token=…, or Authorization: Bearer).

Route Answer
GET /api/health {"status": "ok"}
GET /api/meta Version and base map settings
GET /api/providers Sources, each with the reason it cannot run (or null)
GET /api/budget What each measurement source has left (tests this hour, credits)
POST /api/runs Body {"query": "…"}; starts a run (202), 409 while another runs
GET /api/runs, GET /api/runs/{id} Recent runs; one full report
DELETE /api/runs/{id} Cancel a running run
GET /api/events Server-sent events: ready, run, target, log
