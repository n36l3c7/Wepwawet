Configuration

Wepwawet works without configuration. Settings come from defaults, then the configuration file, then environment variables.

Configuration file

Create ~/.config/wepwawet/config.toml with the settings you want to change:

[server]
host = "127.0.0.1"   # loopback only, unless allow_remote = true
port = 0             # 0 picks a free port at start-up
allow_remote = false

[map]
basemap = "carto"    # "carto" or "offline"

[gui]
rendering = "auto"   # "auto", "software" or "hardware"

[cache]
default_ttl_seconds = 86400
ttl_seconds = { rdap = 604800 }   # per-source overrides

[logging]
level = "INFO"       # DEBUG, INFO, WARNING, ERROR

[measurements]
enabled = true
sweep_probes = 48    # global sweep
zoom_probes = 30     # regional zoom
packets = 3
max_tests = 150      # per target
tcp_fallback_port = 443
traceroute_probes = 5
access_correction = true

[providers.rdns]
sweep = true         # PTR lookups of the /24 neighbours

[providers.local]    # ping from this machine too
lat = 45.46
lon = 9.19

[[providers.ssh.hosts]]   # and from your own servers
name = "vps-fra"
host = "vps.example.net"
user = "probe"
lat = 50.11
lon = 8.68

[providers.ripe_atlas]
max_credits = 300    # RIPE Atlas spends credits only with a budget

[providers.shodan]
enabled = false      # turn any source off

An unknown key or an invalid value stops Wepwawet with a message naming the key.

Key Default Meaning
server.host 127.0.0.1 Address of the local server.
server.port 0 Port; 0 picks a free one.
server.allow_remote false Allow a non-loopback host. Only for a trusted network.
map.basemap carto Base map shown at start-up: carto or offline.
gui.rendering auto How the window draws the map. auto uses software rendering (SwiftShader) in virtual machines and without a GPU render node, where Chromium blocklists the GPU; software always does; hardware also tries a blocklisted driver.
cache.default_ttl_seconds 86400 How long source answers stay cached.
cache.ttl_seconds {} Cache time per source (ripestat, rdap, rdns, peeringdb…).
logging.level INFO Log level for the terminal and the log file.
measurements.enabled true Run the ping campaign after the passive sources.
measurements.sweep_probes, zoom_probes 48, 30 Probes in the global sweep and in the regional zoom.
measurements.packets 3 Pings per probe; the minimum RTT is used.
measurements.max_tests 150 Most tests one target may use (also limited by what Globalping has left this hour).
measurements.speed_km_per_ms 200 One-way speed in fibre for the distance bound (about 2/3 of light in vacuum).
measurements.tcp_fallback_port 443 TCP port to measure when the target drops ICMP; 0 disables the fallback.
measurements.calibrate false CBG calibration: the zoom probes also ping RIPE Atlas anchors of known position and get their own delay-to-distance line. Costs zoom probes × anchors tests.
measurements.traceroute_probes 5 Traceroutes from the fastest probes; 0 disables them.
measurements.access_correction true Remove 80 % of the measured access delay from every RTT before computing the region.
providers.local.lat, lon unset Where this machine is; needed to use it as a probe.
providers.ssh.hosts [] Your servers: name, host, optional user and port, lat, lon. Wepwawet runs ping on them over SSH (key authentication only).
providers.ripe_atlas.max_credits 0 RIPE Atlas credits one measurement may spend; 0 keeps RIPE Atlas off.
providers.<name>.enabled true Turn a source off: geoip, ipmap, ripestat, rdap, rdns, internetdb, shodan, censys, peeringdb, classify, globalping, ripe_atlas, local, ssh.
providers.rdns.sweep true Look up the PTR of the 254 neighbours in the target's /24 (IPv4).

API keys

Keys go in environment variables or in ~/.config/wepwawet/secrets.toml, which must be readable by you only (chmod 600; Wepwawet refuses a looser file): 

[keys]
ipinfo = "…"
maxmind_account_id = "…"
maxmind_license_key = "…"
peeringdb = "…"
shodan = "…"
censys = "…"
Name Variable Used for
ipinfo WEPWAWET_IPINFO Downloading IPinfo Lite (free token)
maxmind_account_id, maxmind_license_key WEPWAWET_MAXMIND_ACCOUNT_ID, WEPWAWET_MAXMIND_LICENSE_KEY Downloading GeoLite2 City and ASN (free account)
peeringdb WEPWAWET_PEERINGDB Higher PeeringDB rate limits
shodan WEPWAWET_SHODAN Shodan host lookups (paid membership)
censys, censys_org_id WEPWAWET_CENSYS, WEPWAWET_CENSYS_ORG_ID Censys Platform host lookups (personal access token)
globalping WEPWAWET_GLOBALPING Globalping token: 500 tests an hour instead of 250 (free)
ripe_atlas WEPWAWET_RIPE_ATLAS RIPE Atlas API key (with max_credits)

Keys are never logged, never shown in the interface and never stored in the cache.

When a source answers "too many requests", Wepwawet remembers how long it asked to wait (up to an hour) and does not call it again before then, even after a restart.

Environment variables

Variable Overrides
WEPWAWET_CONFIG Path of the configuration file (must exist).
WEPWAWET_HOST, WEPWAWET_PORT server.host, server.port
WEPWAWET_BASEMAP map.basemap
WEPWAWET_RENDERING gui.rendering
WEPWAWET_LOG_LEVEL logging.level
WEPWAWET_TOKEN Fixed session token for wepwawet serve (24+ characters); otherwise a new one at every start.

Files

Path Content
~/.config/wepwawet/ config.toml, secrets.toml ($XDG_CONFIG_HOME)
~/.local/share/wepwawet/ GeoIP databases in geoip/, gazetteers in gazetteer/, run history in history.sqlite3, log file ($XDG_DATA_HOME)
~/.cache/wepwawet/ Cache of source answers; safe to delete ($XDG_CACHE_HOME)
